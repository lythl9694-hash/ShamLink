# سند المالية

منصة سند المالية لإدارة الوكالات والموظفين والحوالات المالية.

## التشغيل

يتطلب النظام Node.js 24 أو أحدث.

1. انسخ `.env.example` إلى `.env` أو اضبط متغيرات البيئة في الخادم.
2. اختر قيمة سرية طويلة للمتغير `SHAMLINK_SETUP_TOKEN`.
3. شغّل النظام بالأمر `npm start`.
4. افتح `login.html` وأنشئ حساب صاحب المنصة مرة واحدة باستخدام رمز التأسيس.

لا ترفع ملف `.env` أو قاعدة البيانات إلى GitHub.

## نظام الموافقات

- طلب الوكيل يبقى معلقاً حتى يوافق عليه صاحب المنصة ويحدد وكالته.
- الوكيل ينشئ رابط دعوة للموظف، صالحاً 72 ساعة ولا يُستخدم إلا مرة واحدة.
- حساب الموظف يبقى معلقاً حتى يوافق عليه وكيله.
- الصفحات الحساسة محمية من الخادم بحسب الدور وحالة الحساب.
